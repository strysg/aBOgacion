Más info. de este sitio ↩

Este sitio ha sido construido para facilitar el acceso y lectura a normas Bolivianas vigentes. Estas han sido extraídas principalmente de; lexivox.org y las más recientes de la gaceta oficial del estado plurinacional de Bolivia.

Los datos publicados aquí son de libre acceso y uso, tiene modificaciones de formato para facilitar la lectura pero no cambios en su contenido y cada norma contiene la fuente original.

Las mejoras o modificaciones a este sitio no tienen ninguna garantía, pero si la intencionalidad de aportar herramientas para el análisis, experimentación y para el control social —fundamental para el ejercicio real de la democracia.

Puedes descargar todas las normas de este sitio en formato markdown por si te sirven para hacer análisis de texto. También contribuir con mejoras para este proyecto, aquí tienes disponible el código fuente y los datos.
